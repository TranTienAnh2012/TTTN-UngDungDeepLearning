🧠

AI Service (Flask)

Sử dụng MTCNN phát hiện và căn chỉnh khuôn mặt, kết hợp InceptionResnetV1 (VGGFace2) trích xuất đặc trưng 512 chiều và Cosine Similarity.

☕

Backend Core (Spring Boot)

Spring Boot 3 (Java 17) quản lý nghiệp vụ điểm danh đúng giờ / muộn, xác thực điều kiện dự thi, giao tiếp REST với Python AI.

🌐

WebRTC Client

Giao diện responsive phong cách hiện đại, mở luồng video camera trực tiếp và chụp ảnh Base64 gửi lên máy chủ.
